## 🧠 What is this?

> **AI Learning Lab** is my personal playground for learning, experimenting, breaking things, and building things with Artificial Intelligence.

This repository contains my **learning projects, experiments, implementations, notes, and mini-projects** as I explore the world of:

- 🧠 Artificial Intelligence
- 🤖 Generative AI
- 🧩 Large Language Models
- 🔎 Retrieval-Augmented Generation
- 🗄️ Vector Databases
- 🛠️ AI Agents
- ✨ Prompt Engineering
- 🐍 Python for AI
- 🔥 Machine Learning & Deep Learning
- ☁️ AI APIs & Cloud AI

This isn't meant to be a collection of perfect production projects.

**It's a record of my journey from learning concepts → building systems → becoming an AI Engineer.**
